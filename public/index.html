유의사항

  • 예약 가능 시간은 09:00–21:00이며, 2시간 단위로 예약할 수 있습니다.
  • 예약 취소 및 정보 수정 시에는 예약 당시 설정한 비밀번호 4자리가 필요합니다.
  • 특정 팀의 강의실 독점을 방지하기 위해, 팀당 한 주(월~일) 최대 5타임까지 예약이 가능합니다. 다음 주부터 다시 예약할 수 있습니다.
  • 예약 취소 또는 노쇼가 누적 3회 이상인 경우, 최대 2주간 예약이 제한됩니다.
  • 당일 취소는 불가능합니다. 이용이 어려운 경우 반드시 운영진에게 미리 알려주세요.
  • 노쇼 여부는 출입카드(RF카드) 기록으로 확인되며, 확인된 노쇼는 운영진이 운영진 비밀번호로 "노쇼 처리" 버튼을 눌러 반영합니다.
  • 학생증을 반드시 착용하고, 출입카드로 입실·퇴실 시 태그를 진행해주세요.
  • 예약 접수는 8월 31일부터 시작되며, 지난 날짜는 예약할 수 없습니다.
  • 예약은 당일 기준 2주 앞까지 접수됩니다. 이후 날짜는 매일 하루씩 자동으로 열립니다.
  • 본 예약 현황은 모든 사용자에게 실시간으로 공유되며, 20초마다 자동으로 갱신됩니다.
  • 전체 예약 현황 CSV 내보내기는 운영진 비밀번호가 있어야 가능합니다.
  • 조정이 필요한 경우 운영진에게 문의해주세요.

/** * 연락처(전화번호 또는 이메일)를 권한에 따라 렌더링하는 함수 * @param {string} contact - 원본 연락처 (전화번호 또는 이메일) * @param {boolean} isAdmin - 운영진 인증 여부 * @returns {string} 화면에 표시할 텍스트 */ function getMaskedContact(contact, isAdmin) { if (!contact) return ''; // 운영진인 경우 원본 반환 if (isAdmin) { return contact; } // 이메일 마스킹 (예: gildong@example.com -> gil***@example.com) if (contact.includes('@')) { const [id, domain] = contact.split('@'); const visibleLength = Math.min(3, id.length); const maskedId = id.substring(0, visibleLength) + '*'.repeat(id.length - visibleLength); return `${maskedId}@${domain}`; } // 전화번호 마스킹 (예: 010-1234-5678 -> 010-****-5678 또는 010-1234-****) const cleaned = contact.replace(/[^0-9]/g, ''); if (cleaned.length === 11) { return `${cleaned.substring(0, 3)}-****-${cleaned.substring(7)}` ; } else if (cleaned.length === 10) { return `${cleaned.substring(0, 3)}-***-${cleaned.substring(6)}`; } // 기본 대체 마스킹 return contact.substring(0, 3) + '****'; }
